# Security Policy

## Supported versions

Only the latest version on `main` (the one deployed to GitHub Pages) is supported.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/zalaya/3d-model-visualizer/security/advisories/new).

Include what you found, how to reproduce it and, if you can, a model file that triggers it. You can expect a first answer within a few days.

## Scope

Models are parsed and rendered entirely in your browser; the app has no backend and uploads nothing. Relevant reports are mostly about malicious model files (for example ones that crash or freeze the tab) and about the app's dependencies.
